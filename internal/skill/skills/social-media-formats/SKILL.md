# 社交媒体内容格式

不同平台的读者预期、消费节奏、互动机制完全不一样。**一篇通用稿子贴到所有平台**是最常见的失败模式。

## 平台选择：什么内容发哪里

| 平台 | 典型读者 | 擅长格式 | 不擅长 |
|---|---|---|---|
| Twitter/X | 科技、创业、研究者 | 观点、Hot take、thread、产品更新 | 长篇深度内容 |
| LinkedIn | 职场、B2B | 职业故事、行业洞察、招聘 | 娱乐、消费品 |
| 小红书 | 年轻女性为主、生活方式 | 种草、教程、个人体验 | 纯技术、政治 |
| 知乎 | 中文深度读者 | 长回答、专业科普 | 快节奏消费内容 |
| 微信公众号 | 中文泛读者 | 深度长文、订阅关系 | 即时性内容 |

下面针对 LiteFlow 可能用到的主要平台给出模板。

## Twitter / X

### 核心特点
- 280 字符限制，thread 可以串联
- 前 2 行决定是否点展开
- 反互动算法——分享和引用转推权重高
- 图 / 视频 / GIF 显著提升互动

### 格式 1：单条推文（Single Tweet）

```
[Hook - 一句话抓住注意]
[正文 - 支撑 Hook 的信息]
[可选：反转 / Punchline]
```

好的单条推文三选一：
- **观点**："99% 的 productivity app 都在解决错误的问题：不是整理，是找回。"
- **反常识**："独立开发者最大的敌人不是竞争，是自由度太高。"
- **具体故事**："昨晚用户给我发邮件说他用 LiteFlow 找回了 3 年前的笔记。这是产品最好的反馈。"

### 格式 2:Thread（1/n 系列）

**适用**：教程、深度观点、产品发布

结构：

```
1/ [Hook + 承诺]
   你将学到什么 / 发现什么

2-N/ [主体]
   每条一个点，自成一体
   可以粗体、用数字标记

N+1/ [总结 + CTA]
   重述核心观点
   引导关注 / 点赞转推
```

Thread 写作要点：

- **第一条是整个 thread 的命运**。抓不住人，后面再精彩也没人看
- **每条独立成立**。用户可能跳到中间某条，要能看懂
- **长度控制在 5-10 条**。超过 10 条阅读完成率暴跌
- **最后一条放 CTA**。关注 / 加入 waitlist / 留言讨论

Thread Hook 模板：

- "I spent [时间] doing [事], here's what I learned:"
- "[主题] 的 5 个反常识:"
- "I've reviewed [数量] [对象]。以下是最有效的模式："
- "Everyone talks about X. No one talks about Y. Let me change that."

### 格式 3：Product update（产品更新）

```
🚀 [产品功能] just shipped

What it does:
[一句话说价值]

Why it matters:
[为什么用户会关心]

[GIF / 截图]

Try it: [链接]
```

## LinkedIn

### 核心特点
- 长文更被鼓励（300-800 字）
- 职业相关话题优先
- 第一行决定展开率（"...更多"前的内容）
- 换行密集，每句一行，不要长段落

### 标准格式

```
[Hook - 一句话，独立成行]

[空一行]

[故事开始 / 观点展开]
每一句都独立成行
留白让阅读轻松

[空一行]

[核心观点 / 干货]

- 要点 1
- 要点 2
- 要点 3

[空一行]

[反思 / 收获]

[空一行]

[CTA 或问题引发讨论]
```

### 好 Hook 示例

- "I just got rejected from YC. Here's why I'm celebrating."
- "I fired my best engineer last week. It was the right call."
- "5 years ago I was unemployed. Today I run a $2M ARR SaaS. Here's how:"
- "每个创始人都想多招人。我选择保持 1 个人。以下是原因。"

### 内容主题选择

LinkedIn 什么有效：
- **职业转折**（离职、转行、失败复盘）
- **反常识观点**（挑战行业共识）
- **具体案例 / 数字**（"从 X 到 Y"）
- **招聘帖**（高互动）
- **行业预测**

什么无效：
- 纯产品推广
- 个人生活（婚礼、旅游）
- 政治话题
- 太技术的内容（到 Twitter）

## 小红书

### 核心特点
- 图 / 视频为主，文字辅助
- 标题决定点击，封面决定滑动
- 话题标签非常关键
- 受众女性居多，年轻化

### 标准格式

```
标题：[强吸引力，带 emoji]
例："救命！找到一款治好我效率病的神器 💊"

封面：
- 前 3 个字清晰可读
- 对比强烈的颜色
- 一张"场景感"照片

正文结构：
1. 开场痛点 / 故事（2-3 句）
2. 产品 / 方法介绍
3. 使用步骤（配图）
4. 个人感受
5. 话题标签
```

### 标题模板

- **数字开头**："3 个改变我生活的独立开发者工具"
- **问题开头**："为什么我卸载了 Notion？"
- **情绪词**："救命 / 崩溃 / 绝了 / 神器 / 宝藏"
- **对比**："从 Notion 换到 XX，生产力翻倍的原因"

### 小红书禁忌

- 过度营销（会被判定广告降权）
- 没有个人经历（纯搬运）
- 文字太多图太少
- 标题党但内容空

## 知乎

### 核心特点
- 深度长文友好
- 排版重要（标题、加粗、图）
- 回答比文章流量大
- 找对问题胜过写好回答

### 回答标准结构

```
[前 3 段黄金区]
回答核心结论 / 最抓人的观点
让读者决定"值不值得读完"

[正文]
- 用二级标题分节
- 关键句加粗
- 图表 / 引用丰富
- 每段不超过 5 行

[结尾]
总结 + 个人经验 + 欢迎讨论
```

### 问题选择

好问题特征：
- **浏览量 > 10 万**（有流量基础）
- **答案数量少**（< 50 个，容易排前）
- **和你专业对口**
- **"为什么"、"怎样"类问题**（最适合深度回答）

## 共通技巧

### Hook 写作公式

不管什么平台，Hook 只有几种有效模式：

1. **反常识**："做得多未必做得快"
2. **具体数字**："我用 30 天涨了 10k 粉"
3. **承诺**："读完这篇，你会 XX"
4. **冲突 / 故事开头**："昨天我做了一个让团队骂了我一下午的决定"
5. **直接挑战**："你的 XX 是错的，这才是对的"

### 长度权衡

- **Twitter 单条**：越短越好，留白促分享
- **Twitter thread**：5-10 条最优
- **LinkedIn**：300-800 字
- **小红书**：150-300 字正文 + 3-5 张图
- **知乎回答**：800-2000 字
- **公众号**：1500-3000 字

### Hashtag 策略

- **Twitter**：1-2 个，多了显得垃圾
- **LinkedIn**：3-5 个，行业相关
- **小红书**：5-10 个，覆盖大小流量池
- **知乎**：不需要

## 常见陷阱

| 陷阱 | 症状 | 修正 |
|---|---|---|
| 一稿多投 | 同内容贴所有平台 | 至少改 Hook 和格式适应平台 |
| 开头自我介绍 | "大家好我是..." | 直接进主题 |
| 信息密度过高 | 每句都重要 | 适度留白，让读者喘息 |
| 忘记 CTA | 读完不知道干什么 | 结尾引导关注 / 讨论 / 点击 |
| 标题过度承诺 | 标题党内容空 | 只承诺能兑现的 |
| 不互动 | 发完就走 | 前 30 分钟回复评论提升权重 |

## 起草清单

发之前检查：

1. **平台对吗？** 这个内容最适合发在哪？
2. **Hook 够强吗？** 前 1-2 行能抓住人吗？
3. **有具体吗？** 换掉所有抽象词为具体数字 / 场景
4. **长度合适吗？** 符合平台最佳长度
5. **有视觉吗？** 图 / 视频 / GIF 准备好了？
6. **CTA 清晰吗？** 读者知道读完做什么吗？
7. **发布时间对吗？** 目标读者活跃时段

回答完再发。每个平台的运营节奏和最佳时段不同——Twitter 早上、LinkedIn 工作日上午、小红书晚上——错过高峰期效果会打折。
