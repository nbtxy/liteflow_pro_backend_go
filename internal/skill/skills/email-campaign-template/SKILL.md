# 营销邮件模板

邮件是最老的数字营销渠道，也是最难做对的。大多数"营销邮件"直接进垃圾箱的原因不是被拒绝，而是**发件人从未被打开**。

## 邮件营销的真相

一封营销邮件的命运分三步：

1. **主题和发件人** → 决定是否打开（85% 邮件死在这里）
2. **前 2 句内容** → 决定是否读完
3. **CTA** → 决定是否行动

每一步的漏斗都很窄。通用基准：

- **打开率**：20-30% 算正常，40%+ 算优秀
- **点击率**：2-5%
- **转化率**：0.5-2%

这意味着发 1000 封，最终行动的可能只有 5-20 人。**所以邮件的关键是写给对的人**——列表质量比文案质量重要。

## 邮件类型

不同类型用不同模板。

### 1. Cold Email（首次陌生联系）

**目标**：建立对话，而非直接成交

**最重要的原则**：**短**。200 字以内是上限。

**结构**：

```
Subject: [极具体、个性化，不像群发]

[称呼 - 对方名字]

[开场 - 证明你研究过对方]
我看到你最近在 [具体事件]，注意到 [具体观察]。

[价值主张 - 为什么联系他]
我们做的 [产品 / 服务] 帮助 [类似用户] 解决了 [具体问题]，
比如 [一个具体案例结果]。

[低承诺 CTA]
下周二有 15 分钟聊聊吗？如果不合适，完全理解。

[签名]
```

**好 Cold Email 示例**：

```
Subject: Lisa, 你在 LiteFlow 博客的那篇 multi-agent 设计

Hi Lisa,

看了你上周关于 multi-agent 架构的博客，特别是你说"子 Agent 不应该看完整对话历史"
这点让我印象很深，我们团队在 AutoGPT 项目里走过一样的弯路。

我在 XX 做开发者工具，我们帮 5 家类似 LiteFlow 的团队从多 Agent 架构过渡到
生产环境。我们写了一份关于 token 预算管理的 playbook，我觉得你可能用得上。

需要我发给你吗？如果不需要完全理解。

Thanks,
[Name]
```

**为什么这封有效**：
- 主题不像群发（用了对方名字 + 具体事件）
- 开场证明读过她的内容
- 没有立刻推销，先给价值
- CTA 极低承诺（就发一份文档）
- 主动给出 "No 也没关系"

**Cold Email 的死亡信号**：

- "Hope this email finds you well"
- "我是 [公司] 的 [头衔]"
- "我们是行业领先的..."
- 介绍自己超过 2 句
- 附上长长的公司 PPT

### 2. Newsletter（定期订阅内容）

**目标**：长期陪伴 + 品牌建立 + 偶尔转化

**结构**：

```
Subject: [反应内容本质，不追求点击率]

[一段开场 - 这期要讲什么 / 个人化几句话]

[主体 1-3 块内容]
每块：
- 粗体小标题
- 2-4 段正文
- 相关链接（最多 2 个）

[本周推荐 - 可选]
- 1-3 条短推荐

[结尾]
签名 + 轻量 CTA（回复问题 / 转发 / 反馈）
```

**Newsletter 的关键原则**：

- **真实的"一个人"在写**：不是企业官方腔，是个人在分享
- **定期 > 频繁**：每两周写一篇好的，比每周写两篇凑数的有价值
- **不追求立刻转化**：信任是长期的，每期都卖东西会取关
- **留钩子**：每期结尾暗示下期内容，让人期待

### 3. Welcome Email（欢迎邮件）

**目标**：让用户第一时间用起来，降低流失

**结构**：

```
Subject: 欢迎！先做这件事 👋

[称呼]

谢谢你注册 [产品]！

我是 [名字]，[产品] 的创始人 / 负责人。

[一句话重申产品价值]

如果你现在只有 3 分钟，做这件事：
→ [具体的第一步，最小可行动作]

如果你有 10 分钟，我推荐这样开始：
1. 做 X
2. 然后 Y
3. 最后 Z

有任何问题直接回复这封邮件，我会亲自看。

[签名]

P.S. [有个性的一句话，建立人味]
```

**关键**：
- 来自"人"不是来自 "team@"
- 给一个**极具体的第一步**（3 分钟能做完）
- 真的邀请回复（并且真的要回）
- P.S. 很重要——是阅读率第二高的部分

### 4. 唤醒邮件（Re-engagement）

**目标**：让沉睡用户回来

**结构**：

```
Subject: [情感化或疑问]
例："是我哪里做错了吗？"
   "你还在吗？"
   "最后再打扰你一次"

[称呼]

[坦诚的观察]
你已经 X 周没打开 [产品] 了。

[同理心]
我知道大家都很忙。也许 [产品] 没有真正帮上你。

[给个台阶]
我想问你：是因为 A（比如没找到使用场景）还是 B（产品体验不好）？
直接回复一个字母就好。

[可选：新功能 / 改进提示]
顺便告诉你，上个月我们改了 XX，也许解决了你之前遇到的问题。

[低压力 CTA]
如果你想重新试试：[链接]
如果想取消订阅：我完全理解 [取消链接]

[签名]
```

**关键**：
- 不装作什么都没发生
- 提供取消订阅的出口（反而降低取消率）
- 单字母回复降低响应门槛

### 5. 产品更新邮件（Product Update）

**目标**：通知新功能 + 引导使用

**结构**：

```
Subject: [功能名] + 价值

例："全新的搜索，现在快了 10 倍"
   "你要求的 X 功能来了"

[开头一句]
我们刚刚上线了 X。

[价值]
它让你 [具体能做什么]。

[截图 / GIF]

[如何使用 - 1-2 步]

[CTA]
马上试试：[链接]

[P.S. 听反馈]
有任何想法直接回复。
```

## 主题行（Subject Line）

主题行是邮件的 80%。

### 好主题的 5 个特征

1. **具体**："我们有新功能" → "邮件搜索现在能理解自然语言了"
2. **个性化**：包含对方名字或他关心的东西
3. **好奇心**：引发想点开的冲动，但不标题党
4. **短**：40 字符以内，移动端只显示这么多
5. **不像营销**：避开所有典型营销词

### 好主题模板

- **提问**："你每周在 XX 上花多少时间？"
- **具体数字**："3 个改变我工作方式的小工具"
- **反常识**："为什么我们删掉了最受欢迎的功能"
- **个人化**："[名字]，关于你上次的问题"
- **实用**："如何在 30 秒内 XXX"
- **时间紧迫**（少用）："本周五前有效"

### 死亡主题词

这些词大幅提高进垃圾箱概率：
- "免费"、"Free"、"100%"
- "紧急"、"Urgent"
- "保证"、"Guarantee"
- 全大写
- 多个感叹号
- 货币符号

## 预览文本（Preview Text）

大多数邮件客户端在主题后显示一段预览文本（通常是邮件第一句）。

**好预览文本**：
- 不重复主题
- 延续主题的诱惑
- 补充一个关键信息

**差预览文本**：
- "View this email in browser"
- "Hi [Name]"（浪费了宝贵展示位）
- "If you don't want to receive..."

## 正文写作

### 第一句决定一切

打开邮件后，第一句决定是否读完。

**弱第一句**：
- "Hope this email finds you well"
- "My name is X from Y company"
- "We are the leading provider of..."

**强第一句**：
- "你昨天在 Twitter 上说的那个问题，我们做了一个工具。"
- "一个坏消息和一个好消息。"
- "请允许我直接说重点。"

### 段落长度

移动端阅读，**每段 2-3 行**最多。看到长段落用户直接关闭。

### CTA 设计

**一封邮件一个主 CTA**。

好 CTA 按钮文字：
- "免费试用 14 天"（具体 + 零风险）
- "看看如何运作 (2 分钟)"（低承诺）
- "领取你的访问权限"（独占感）

差 CTA：
- "Click here"
- "Submit"
- "Read more"（大家都知道这是在"读更多")

## 常见陷阱

| 陷阱 | 症状 | 修正 |
|---|---|---|
| 列表不对 | 发给所有人同一封 | 按用户行为分群 |
| 主题套路 | "🎉 特惠！最后机会！" | 用真实感的主题 |
| 开头啰嗦 | 前 100 字都在自我介绍 | 第一句就进重点 |
| 多 CTA | 邮件有 5 个按钮 | 砍到 1 个主 CTA |
| 太像群发 | 无个性化 | 至少加名字 + 一个具体细节 |
| 没有 P.S. | 浪费了阅读率第二高位置 | 加个人化的 P.S. |
| 太长 | 1000+ 字 | Cold email ≤200 字，其他按需 |

## 起草清单

写之前回答：

1. **这封邮件的唯一目标是什么？**（一个动作）
2. **收件人是谁？** 他们当前在做什么 / 想什么？
3. **这封邮件是他们读 /不读** 都无所谓吗？如果无所谓，不要发
4. **主题是否具体、不像营销？**
5. **前 2 句能抓住人吗？**
6. **CTA 是否清晰、低承诺？**
7. **收件人会回复吗？** 如果连回复都不会，改低 CTA
8. **发件人是"人"还是"team@"？**（优先用人）

回答完再写。**如果你自己都不会打开这封邮件，别的人也不会。**
